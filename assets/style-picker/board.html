网页截图怎么放进公众号

示例文章

写工具教程时，截图往往比文字先吸引注意。读者可能只扫一眼，就想知道自己该点哪里、下一步会看到什么。拿一张 GitHub 仓库截图做例子，从选图到手机预览，可以依次检查这四处。

先确定要展示的内容

先想清楚这张图要回答什么。如果你正在教读者从仓库里找到说明文档，就把仓库名、文件列表和 README 的位置留在同一张图里。截完用手机宽度看一遍，确保文件名还能认出来，读者就能照着你的步骤找到入口。

给截图留一点边

给截图加背景时，可以先看画面里哪一处最需要读者注意。这里主要看文件列表，所以背景只在四周露出一圈，让界面里的文字有足够的空间。选好底色后，把图片缩到正文栏宽，再看一次最小的字是否清楚。

让读者找得到下一步

章节标题可以直接告诉读者这一段要做什么。比如把「截图」写成「先确定要展示的内容」，读者往下扫时就知道这里讲的是取舍。每一节先把当前步骤和判断依据讲完，再进入下一节。这样读到一半放下手机，回来也容易接着看。

在手机上再看一遍

最后用手机从标题一路滑到文末。开篇横幅后面应该很快读到第一段，正文里的图片也要和上下文接得上。遇到需要放大才能看清的截图，可以重新截取更小的区域。看到文末贴纸时，读者应该已经顺利读完最后一个步骤。
