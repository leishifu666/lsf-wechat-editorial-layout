# 公众号真实截图配图：Kuang 默认设置

雷师傅于 2026-10-23 指定。用于公众号工具教程、操作实录、界面对话等截图配图；
不把这套背景套用于所有封面、生图或网站设计。用户本轮的明确要求覆盖本机默认。
本页对应「01 日落 · Moonvy」。其他背景见 [截图背景](style-picker.md#截图背景)。

## 选图

- 从当前文章、当前视频或当前对话中取实际画面；有源截图时优先使用清晰源图。
- 只截能说明该段内容的区域，保留必要界面和完整文字；避开缩放动画、半行文字、空白和无关侧栏。
- 图片说明对应实录事实。截图美化不重画界面、改写截图里的文字或制造未演示的结果。
- 原图和过程记录留在任务工作目录；文章旁保存 `<文章名>-assets/`，带图稿另存，保留正文原稿。

## 固定样式

打开 <https://moonvy.com/apps/kuang/editor.html>，用实际网页控件确认：

| 项目 | 默认值 |
| --- | --- |
| 布局 | 经典居中 |
| 画布 | 自适应，按比例调整 |
| 氛围背景 | 日落 |
| 底色 | `#F7F1EC` |
| Aura 颜色 1 / 2 / 3 | `#FF6B6B` / `#FFB86B` / `#D66DFF` |
| 颗粒 | 关闭 |
| 图片圆角 | 中，3% |
| 边框留白 | 中，8% |
| 投影 | 光晕 |
| 光晕颜色 | `#FFB86B` |
| 光晕大小 / 强度 | 64% / 68% |
| 区域高亮、文字描述 | 默认关闭，文章需要标注时再单独判断 |
| 导出外框圆角 | 开启 |
| 导出 | 2× PNG |

圆角、留白、光晕数值是在用户指定截图对应的已恢复项目中展开面板核对得到。
画布的宽高随源图变化，不固定成参考图的 771×773；“适应/100%”是编辑器预览缩放，
无需为了相同外观强制预览百分比。保留日落预设的柔光位置与扩散，不用“智能匹配”或“AI 样式”替换它。

## 网页导出与检查

- 使用当前可用浏览器技能操作真实网页。优先复用已恢复的相同设置；换图后回读设置，避免重置。
- 2026-10-23 实测：编辑器 `#fileInput` 可经浏览器原生文件上传控件更换图片并保留外观。
  每张导出前核对当前文件名、经典居中、日落、自适应和 2×。选择器变化时重新检查页面，不猜内部接口。
- 先监听下载，再点“导出 PNG”，将实际下载文件保存到任务的配图目录。
  不用整个编辑器页面的截图充当导出结果，不用本地仿制背景冒充 Kuang 导出。
- 检查实际 PNG 的格式、像素和画面。2× 导出应接近画布宽高的两倍，浮点布局取整可能相差 1 像素。
  逐图确认文字、主体、圆角、留白和渐变，没有裁掉关键内容或带入编辑器控件。
- 只为需要解释的段落插图，不按固定张数凑图。保留下载结果和简短来源/参数记录，便于后续改图。
- 网站或导出不可用时保留清晰原截图并说明缺口，不能把替代处理写成已使用网站完成。
