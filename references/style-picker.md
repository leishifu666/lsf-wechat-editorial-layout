# 公众号样式动效预览

开工时生成 Dinamo HTML，并发可直接打开的预览链接。桌面最左侧是独立预设栏，中间按开篇署名、章节标题、截图背景、文末贴纸的顺序选样，右侧实时预览本篇稿件或示例。窄屏点顶部「预设」打开面板，手机可点「看效果」直达刚改过的文章位置。开篇按「文案来源 → 文字 → 动效」三步选择。各组默认展示第一款。

选好后点「复制选择」，把稿件标题、编号、款名、文案状态和可选意见粘贴回对话。补充意见默认折叠。预设保存在同一浏览器和同一预览来源（协议、主机和端口）内。换设备或端口时，用左栏「备份预设」导出 JSON，再在新预览导入。同名预设会保留本机版本。备份包括已保存的开篇文字、样式和 Logo。

| 选项 | 生成参数 | 编号 |
| --- | --- | --- |
| 开篇动态署名 | `--group intro` | 29 款，沿用原编号 |
| 章节标题样式 | `--group chapters` | 01 动态字母，02 动态数字 |
| 文末贴纸 | `--group stickers` | 01 星球变火箭，02 AI 图标旋转环，03 趣味贴纸旋转环，00 本篇不加 |
| 截图背景 | `--group backgrounds` | 01–14、A01–A14，见 [背景目录](kuang-screenshots.md) |

左栏同时显示署名动效、章节标记、文末贴纸以及截图背景小样，点小样即可选中。字母组和数字组各展示四枚标记，右栏也将它们放入对应章节。正式排版时从 INITIĀLIS 原站抽款。文末贴纸在示例中用代表配色，选定设计后按文章选配色，用户点名配色时直接用指定版本。

开篇署名款式放在一个网格里，每页最多三行。翻页浏览时保留当前选择，可点「已选在第几页」返回；套用预设时自动显示所选款式所在页。左栏保留轻量小样，右栏只启动当前所选的实时渲染。改署名或文章短句后，右栏更新实际文字，复制结果也使用最新文案。各款可导出当前所选的 640×260 循环 GIF 或 PNG 静帧。新增款式时检查编号、小样、实时文案及实际下载文件。

「手写署名」优先载入已保存署名。切到「Agent 提炼文章」时，首次回填框为空，文章开篇显示等待回填。复制选择会附上按正文提炼的任务。拿到短句后粘贴回填，再手改、预览或导出。只有已确认的文案才用 `--intro-line` 显式回填。

## 带入本篇稿件

从用户给的原稿整理 UTF-8 JSON，保留原文、段落顺序与配图位置。预览直接复用 [正式 HTML 模板](../assets/article-template.html) 的正文、章节、图片和图注样式。示例：

```json
{
  "title": "本篇文章标题",
  "intro": ["开头第一段"],
  "chapters": [
    {
      "title": "第一节",
      "paragraphs": [
        "正文里的<strong>重点</strong>。",
        {"screenshot": "images/screen.png", "caption": "实际操作界面"},
        {"image": "images/photo.jpg", "caption": "普通配图"}
      ]
    }
  ]
}
```

```sh
python -X utf8 scripts/build-style-preview.py --article "稿件.json" --output "公众号稿件预览.html"
```

配图路径相对于 JSON 文件。普通 `image` 保持原图，`screenshot` 应用所选背景。多张截图的更换与导出按钮在各图下方。稿件没有章节或截图时，自动略过相应选项。正式稿仍按本篇抽取记录生成章节标记。

## 生成与更新

在 Skill 根目录执行下列命令，将输出路径换成当前任务的交付目录。默认展示全部选项。只需补选一项时加上对应的 `--group`。文章没有截图时加 `--group motion`，只展示动效。

```sh
python -X utf8 scripts/build-style-preview.py --author "雷师傅" --output "公众号样式动效预览.html"
```

生成后用浏览器打开，确认样品与编号对应、动效正常、选项可切换，且「复制选择」复制了当前选项和填写的意见。每次调整素材或索引后重新生成并检查。新增字母或数字款时更新对应目录的 `styles.json`，新增贴纸配色时更新该设计的 `palette-index.json`。署名款用稳定的内部 ID，显示编号沿用已分配的编号，移除款式时保留空号，其他选项沿用索引里的稳定编号。[素材索引](../assets/style-picker/catalog.json)

| 维护层 | 文件 |
| --- | --- |
| 生成入口 | [build-style-preview.py](../scripts/build-style-preview.py) |
| 选样界面 | [布局](../assets/style-picker/board.html) · [样式](../assets/style-picker/board.css) · [选择、复制和预设](../assets/style-picker/board.js) |
| 选项与分类 | [四组选项](../assets/style-picker/catalog.json) · [署名动效](../assets/design-how/catalog.json) |
| 动效实现 | [署名组件](../assets/intro-wordmark/wordmark.jsx) · [效果注册](../assets/intro-wordmark/vault-demos.jsx) |

在同一台电脑的 Codex 桌面端，把生成的 HTML 放进现有预览目录。优先沿用已在用的 `127.0.0.1:5841`，使本篇稿件和选样页共用预设。没有运行中的预览服务时可用下列命令启动。确认页面加载成功，再发可点击的 HTTP 链接。只服务预览目录。

```sh
python -m http.server 5841 --bind 127.0.0.1 --directory "预览目录"
```

预览链接示例为 `http://127.0.0.1:5841/`。若用户在另一台设备，使用该会话提供的可访问预览方式，或交付可直接打开的 HTML 文件附件并说明本机链接的范围。

## 截图背景

完整 Dinamo 预览的截图背景共用一套分页网格，每页最多三行，样卡以「渐变」或「图片」标注类型。左栏样卡只显示底色或背景图，右栏用实际截图预览选中的背景。选择有馆藏来源的图片后，可从右栏打开原作。

默认示例用雷师傅公开的 GitHub 仓库实拍。28 款背景共用同一张原图。截图保留原比例，内外框均有圆角，四边留白统一为原截图短边的 8%。左栏可点「更换截图」导入本篇原图，再点「导出 PNG」下载所见成品；图片只在当前浏览器里处理。

也可以生成时直接嵌入本篇原图：

```sh
python -X utf8 scripts/build-style-preview.py --screenshot "原始截图.png" --output "公众号样式动效预览.html"
```

预览与 PNG 用同一幅画布。通常导出宽 1200 px，特别长的图限制在 4096 px 高。导出后检查外圆角透明、截图文字清楚。图注在文章里单独排。将 PNG 上传微信后，再检查实际图片边缘和文字。
