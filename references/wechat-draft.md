# 公众号配图与草稿交付

## 读者可见的出处

雷师傅的公众号成稿默认省略出处说明，包括正文内的「能力参考」「见官方指南」等引文提示、资料核对日期、文末参考资料和网址清单，以及图注中的来源和背景出处。资料可在工作记录里留存，公众号稿件保留解释画面或帮助读者操作的文字。用户本篇明确要求列出处时，按本篇要求处理。

## 截图和图注

- **图文配图用截图工具实际截取**。网页、软件界面、产品操作截图取自实际页面；文字图解可先制作 HTML，再通过截图工具导出 PNG。不要用绘图库或生图模拟截图后声称已截图。
- **截图加背景、留白与圆角后再进入公众号**。沿用本篇选定的背景；用户交由默认时用「01 日落」。所有背景均内置，见 [背景目录和来源](kuang-screenshots.md)。
- 截图后先打开原图，确认内容完整、可辨、没有空白或裁错。导出加背景的成品后再次查看。记录截图来源与主题，避免把账号资料、令牌、私信等无关信息带入配图。
- **图片下方的简短图注，末尾不加中文句号或英文句点**。例如“标题与绿色轻强调”，不要写成“标题与绿色轻强调。”。这一规则只约束图注，不删除正文正常句号。
- 图注用可编辑文字，放在图片下方；不要为了图注再把整段正文截图。
- 文章正文保持可编辑；配图才转为图片。已有标题和文章主题直接使用，封面不作为普通配图的额外审批步骤。

## 编辑器操作

1. 检查稿件与已存在的草稿，保护用户已有修改。只在当前授权文章中调整。已有登录态和草稿就复用。
2. 在浏览器实际打开截图来源。优先用当前浏览器提供的截图 API；例如 Ego Browser 的 `page.screenshot()`。按该工具当前文档操作，不猜测方法。图解可用自己的 HTML 版面作为截图来源，明确标注为示意。
3. 对准内容区域截图，保留清晰的原始分辨率。在 scrolled 页面使用 clip 时先确认坐标系；无法保证时先回到页面顶部再截，或直接截完整可见区。不要只因文件生成就认定截图成功。
4. 在 Dinamo 的 [截图背景](style-picker.md#截图背景) 里更换原图，选择本篇背景，点「导出 PNG」。稿件有多张截图时，在右侧各张截图下分别更换或导出。逐张打开下载文件，检查圆角、留白和文字。图注作为正文文字放在图片下方，末尾不加句号。
5. 将 **带背景的截图成品** 通过公众号“图片 → 本地上传”实际上传，等待微信图片地址及图片加载成功。正文使用上传后的图片地址，不把本地文件路径或 base64 当成已完成上传。
6. 通过带 `text/html` 与 `text/plain` 的富文本粘贴或编辑器正常操作放入正文，文字用内联样式。首次使用当前编辑器时先验证一个小区块，再批量写入；粘贴、上传、保存均等待可观察状态，避免异步操作尚未完成就继续。
7. 用户要求“放到公众号看 / 草稿展示”即授权本次上传与保存草稿，直接完成。仅要求本地排版时不写入账号。保存草稿不等于授权发表、群发或发送给他人。
8. 在**公众号实际编辑器**中查看图片、图注和上下段落，核对美化背景已出现、主体完整、文字清晰、宽度与留白合适、图注无末尾句号。打开微信“预览”查看原生效果；需要封面时可复用本篇已上传配图。记录保存成功，不能只拿本地 HTML 截图作为公众号验证。
9. 将公众号实际效果的截图留作证据，打开查看后再交付。如果截图失败或微信预览受限，说明未验证项，并保留已保存草稿。真实手机效果需实际打开后才能声称已验证。

## 本地预览与反馈

本地预览保留“复制到公众号”按钮，只复制正文。微信图片可能有防盗链限制，本地显示截图文件，复制时替换为微信上传地址；不要把防盗链占位图误当成原图加载成功。预览页面应在375/768/1440宽度查看；已进入公众号的正文以微信实际呈现为准。

交付说明草稿标题、图片数量、公众号实测情况及未验证项。按用户指出的具体位置持续修改，并将明确确认的样式偏好更新到本技能；不把一次临时选题、账号ID或截图示例变成全局规定。
